# Roundtable

Use `roundtable ask` or the `roundtable_ask` MCP tool when independent model perspectives materially improve a decision.

- Default to advisory mode (`rounds=1`).
- Use `rounds=2..3` only when cross-examination is useful.
- Use research mode only for current external facts; unavailable heads are excluded fail-closed.
- Preserve per-head answers, the chair verdict, agreements, and dissent.
- Do not request, paste, store, or infer API keys. Authentication belongs exclusively to official CLI login flows.
